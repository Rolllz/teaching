Домашнее задание. ```Vagrant-стенд c VLAN и LACP```

Цель домашнего задания ```Научиться настраивать VLAN и LACP.```

Описание домашнего задания
```
  в Office1 в тестовой подсети появляется сервера с доп интерфейсами и адресами в internal сети testLAN: 
- testClient1 - 10.10.10.254
- testClient2 - 10.10.10.254
- testServer1- 10.10.10.1
- testServer2- 10.10.10.1

  Равести вланами:
testClient1 <-> testServer1
testClient2 <-> testServer2

  Между centralRouter и inetRouter "пробросить" 2 линка (общая inernal сеть) и объединить их в бонд, проверить работу c отключением интерфейсов
```

В данном ДЗ был использован Debian 12.

Vagrant отказался добавлять бокс с CentOS 8 Stream. Как оказалось, нет совпадения между облаком Vagrant и CentOS. Поэтому вместо CentOS тоже был использован Debian.

Последняя версия Vagrant не может добавить сетевые интерфейсы так, как это указано в методичке, поэтому пришлось добавлять для каждой машины вручную.

Судя по схеме сети, представленной в методичке, office1Router подключен к testVLAN двумя разными сетями: vlan1 и vlan2. Однако virtualbox не может обьединить несколько внутренних сетей в одну (за этим они и были созданы отдельно), поэтому выход в инет через inetRouter не представляется возможным, так как virtualbox видит, что office1Router никак не связан с testClient1,2 и testServer1,2. От office1Router выход в инет через inetRouter обеспечен с помощью iproute2 и nftables. Машины в сети testVLAN общаются только внутри своих VLAN'ов.
