Домашнее задание. ```VPN```

Цель домашнего задания
```
Создать домашнюю сетевую лабораторию. Научится настраивать VPN-сервер в Linux-based системах.
```
Описание домашнего задания
```
1.  Настроить VPN между двумя ВМ в tun/tap режимах, замерить скорость в туннелях, сделать вывод об отличающихся показателях
2.  Поднять RAS на базе OpenVPN с клиентскими сертификатами, подключиться с локальной машины на ВМ
```

В данном ДЗ был использован Debian 12.

ДЗ реализовано с помощью Ansible ролей, каждая на пункт ДЗ. Для проверки надо лишь закомментировать одну из ролей в основном плейбуке.

Выводы по результатам выполнения ДЗ:

1)  Режимы "tun" и "tap" практически не отличаются по скорости. Разница буквально в несколько мегабит в секунду в пользу tun. Возможная причина: работа на сетевом уровне, а не на канальном, поэтому надо инкапсулировать меньше уровней в пакете.
2)  В первом пункте ДЗ необходимо лишь ввести команды на каждой машине для проверки скорости через iperf3.
3)  Во втором пункте ДЗ реализовал подключение клиента через юнит сервиса, как и в первом, так как при вводе команды приходится открывать еще один терминал для проверки соединения на клиенте. Так же, как и в первом пункте, необходимо лишь пропинговать машины в туннеле.
