Домашнее задание. Сценарии iptables.

Цель домашнего задания

    Написать сценарии iptables.

Описание домашнего задания

```
1.  реализовать knocking port (centralRouter может попасть на ssh inetRouter через knock скрипт)
2.  добавить inetRouter2, который виден(маршрутизируется (host-only тип сети для виртуалки)) с хоста или форвардится порт через локалхост.
3.  запустить nginx на centralServer.
4.  пробросить 80й порт на inetRouter2 8080.
5.  дефолт в инет оставить через inetRouter.
```

  В данном ДЗ был использован Debian 12.

  Настройка Ansible производилась с использованием одного плейбука на все машины.

1.  Knocking port реализован через утилиту knockd, для inetRouter написан отдельный конфиг, который в процессе развертывания и настройки заменяет стандартный. С помощью этой же утилиты centralRouter может попасть на ssh inetRouter.
    На inetRouter установлено правило iptables, блокирующее все входящие подключения по ssh
    На centralRouter необходимо ввести команду knock 192.168.255.1 7000 9000 8000, после чего на inetRouter будет выполнена команда iptables, разрешающая подключение по ssh для этого ip-адреса, и в течение 60 секунд можно попасть на inetRouter по ssh.

2.  inetRouter2 был добавлен в сеть wifi, имеет адрес 192.168.0.66. Виден с хоста через ansible-интерфейс (192.168.56.17). С помощью iptables реализован проброс nginx на centralServer на 192.168.56.17:8080, и с хоста можно попасть на веб-сервер.
    Для этого на inetRouter2 добавлены правила iptables, разрешающие подключения в цепочке FORWARD, а также правила преобращования адресов в таблице nat.
    
  Для сохранения правил iptables на постоянку была установлена утилита iptables-persistent, которая создаёт директорию /etc/iptables. В ней хранятся правила для IPv4 и IPv6: rules.v4 и rules.v6 соответственно. Путем замены пустого файла на готовый при перезагрузке машины правила iptables сохраняются.
