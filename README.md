Домашнее задание:
```
Vagrant-стенд с PostgreSQL
```

Цель домашнего задания
```
Научиться настраивать репликацию и создавать резервные копии в СУБД PostgreSQL
```

Описание домашнего задания

    1) Настроить hot_standby репликацию с использованием слотов
    2) Настроить правильное резервное копирование

В данном ДЗ был использован Debian 12.

Для корректной работы Ansible потребовалась установка дополнительных пакетов на виртуалки:

  -  pexpect (для модуля ansible.builtin.expect)
  -  acl (для работы become_user)

Вместо указанных в ДЗ версий СУБД был использован [репозиторий](https://www.postgresql.org/download/linux/debian/) PostgreSQL, установка последних версий производилась из него.

Для корректной работы barman необходимо произвести выгрузку WAL и архивировать их. За это отвечает параметр ```switch-xlog```. Команда выведена в отдельный таск.
